Hogyan tanulja meg egy új felhasználó az eNvolve-ot?

Az új diák most egy kurzuslistát lát magyarázat nélkül, és az óra indításakor a böngésző váratlanul mikrofon-engedélyt kér. Négy egymásra épülő megoldást javaslok. Mindegyik kicsi, és együtt fedik le az első belépéstől az első óra végéig tartó utat.

2026. október 21. eszközök + akadálymentességi irányelvek Next 16 · React 19 · next-intl
Javaslat

Saját fejlesztés a Driver.js könyvtárral, rövid, oldalankénti túrákkal, egy üdvözlő képernyővel és mikrofonteszttel, valamint segítő szövegekkel az üres oldalakon. A Driver.js ingyenes (MIT licenc), nagyon kicsi, és nincs React-függősége, így a React 19 és a Next 16 nem okoz gondot. A fizetős no-code eszközök havi 100 dollárnál kezdődnek, és kevésbé szabhatók az autista és ADHD-s diákokra.

01

Hol akad el egy új felhasználó?

A jelenlegi kód alapján ezen az öt ponton nem kap magyarázatot. A sorrend egy új diák útját követi.

Kezdőlap

Mi az a kurzus?

A „Népszerű kurzusok” lista nem mondja el, hogy egy kurzus egy hangos óra az AI-tanárral, és hogy saját kurzust is lehet készíteni.

Kezdőlap

Üres „Legutóbbi órák”

Egy új fióknak nincs előzménye, ezért a lista üres. Itt kellene lennie az első lépésnek: „Indítsd el az első órádat”.

Új kurzus

Mit írjak a mezőkbe?

A téma, tárgy, hang, nyelv és időtartam mezőknél nincs példa. Nem derül ki, hogy a téma alapján fog beszélni az AI.

Óra

Váratlan mikrofon-kérés

Az „Óra indítása” után a böngésző engedélyt kér. Ha a diák a „Letiltás” gombra kattint, az óra nem indul, és nem tudja, miért.

Óra

Mikor beszélhetek?

Nem egyértelmű, mikor beszél az AI, mire jó a némítás gomb, és hogy az átirat végig olvasható.

A legfontosabb a 4. pont. Ha az engedélyt egyszer letiltják, a böngésző többé nem kérdez rá magától, és a diák csak a beállításokban tudja visszakapcsolni. Ezért előre kell szólni neki, és ki kell próbáltatni vele a mikrofont még az óra előtt.

06

Szabályok autista, ADHD-s és tanulási nehézséggel élő diákoknak

A W3C kognitív akadálymentességi (COGA) irányelveiből, a túrára lefordítva. Ezek a TDK-dolgozatban is jól hivatkozhatók.

Fókusz
Egy lépés, egy dolog. Legfeljebb 3–5 lépés túránként, egy lépésben egy gomb, két rövid mondat.
Tájékozódás
Mindig látszik, hol tart. Haladásjelző („2 / 5”), és a gombok mindig ugyanott vannak.
Tempó
Nincs időkorlát. Nincs automatikus továbblépés. A diák lép tovább, amikor készen áll.
Kontroll
Bármikor kihagyható és újraindítható. A navigációs sávban lévő „?” gombbal a túra újra elindul.
Kiszámíthatóság
Előre szól. A mikrofon-kérés előtt elmondja, mi fog történni, és mit kell választani.
Nyelv
Egyszerű mondatok. Tegeződve, szakszavak nélkül, ikon és szöveg együtt.
Olvasás
Felolvasás gomb. A lépés szövegét a böngésző felolvassa, vagy előre elkészített ElevenLabs-hangfájl szól ugyanazzal a hanggal, mint a tanár.
Inger
Csökkentett mozgás. Ha a gépen be van kapcsolva a „kevesebb animáció”, a túra animáció nélkül fut. Nincs villogás és nincs automatikus hang.
Kezelés
Billentyűzettel is megy. Nyilak és Esc a túrában, nagy kattintható gombok.
Emlékezet
Nem kell megjegyezni. Ami a túrában elhangzott, az kis segítő szövegként a helyén marad.
07

Kód és tárolás

A kiemelendő elemek egy data-tour attribútumot kapnak, így a túra nem törik el, ha a CSS-osztályok változnak. A szövegek egy új Tour részbe kerülnek a fordítási fájlokban.

components/tour/useTour.ts (vázlat)

"use client";
import { driver } from "driver.js";
import "driver.js/dist/driver.css";

export function useTour(id: TourId) {
  const t = useTranslations("Tour");
  const { user } = useUser();

  const start = () => {
    const calm = matchMedia(
      "(prefers-reduced-motion: reduce)").matches;
    driver({
      showProgress: true,
      progressText: "{{current}} / {{total}}",
      nextBtnText: t("next"),
      prevBtnText: t("back"),
      doneBtnText: t("done"),
      animate: !calm,
      steps: TOURS[id].map((key) => ({
        element: `[data-tour="${key}"]`,
        popover: {
          title: t(`${id}.${key}.title`),
          description: t(`${id}.${key}.text`),
        },
      })),
      // megjegyzi, hogy ezt a túrát már látta
      onDestroyed: () => markSeen(user, id),
    }).drive();
  };
  return { start };
}

09

Amiről nektek kell dönteni

?
Kötelező legyen az üdvözlő képernyő?
Javaslat: első belépéskor megjelenik, de egy gombbal kihagyható. A kötelező lépések az ADHD-s diákoknál könnyen lemorzsolódáshoz vezetnek.
?
Kell külön túra a tanároknak?
Most még nincs tanári szerepkör az alkalmazásban. Ha lesz, ugyanez a rendszer kap egy második túrakészletet.
?
Legyen hangos bemutató óra?
Ez a legkülönlegesebb rész, de minden indítás Vapi-perceket fogyaszt. Lehet ingyenes, például az előfizetési korlátba nem beleszámító, egyszeri bemutató.
?
Mérjük-e a túrák használatát?
A TDK-hoz nagyon hasznos adat. Kiskorú diákoknál viszont adatkezelési tájékoztató és szülői hozzájárulás kell, ezért érdemes anonim eseményekkel kezdeni.
