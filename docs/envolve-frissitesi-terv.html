01

A Daily helyzete

A Vapi a hangkapcsolathoz a Daily nevű könyvtárat használja. A Daily rendszeresen emeli a legrégebbi támogatott verziót, és a régebbiekre hibát ír ki. Erről a hibáról volt szó a teszt során.

daily-js 0.84Vapi SDK 2.5.0 (a projekt eredeti állapota)Nem támogatott
daily-js 0.87Vapi SDK 2.7.1 (a legutóbbi javításom). 2026. aug. 26. óta ez a legrégebbi támogatott verzió.Hamarosan lejár
daily-js 0.89A Daily szerint ez is a támogatás vége felé járLejár
daily-js 0.93Vapi SDK 3.0.0, megjelent 2026. okt. 16-ánTámogatott

A 0.87-re való frissítés eltüntette a hibaüzenetet, de csak rövid időre: ha a Daily 0.89-et a támogatás végéhez közelinek tartja, a 0.87 is hamarosan kiesik. A 3.0.0-s Vapi SDK a 0.93-at hozza, ami jóval tovább kitart.

02

Mi változott a Vapi 3.0.0-ban?

A 3.0.0-hoz még nincs kiadási jegyzet, ezért letöltöttem a 2.7.1-es és a 3.0.0-s csomagot, és fájlonként összevetettem őket.

Mit néztem2.7.13.0.0Eredmény
A program kódja (vapi.js, client.js)azonosNincs viselkedésbeli változás
A típusdefiníciók (vapi.d.ts, api.d.ts)azonosA mi kódunkhoz nem kell nyúlni
@daily-co/daily-js^0.87.0^0.93.0Ez a fő változás
Node.js minimum18.0.022.14.0Ellenőrizni kell, ez miatt major a verzió

A Node 22.14-es követelmény a fejlesztői gépedre és a Vercelre vonatkozik. Gépen: node -v. Vercelen: Project Settings → Build and Deployment → Node.js Version, ami legyen 22.x vagy újabb. A Daily 0.89-es törő változása csak saját magunk által hosztolt hívásmotorra vonatkozik, a Vapi ilyet nem használ.

03

A teljes projekt: 27 elavult csomag, három csoportban

1. lépés · most

Biztonságos frissítések

Verzión belüli (minor/patch) frissítések. A szemantikus verziózás szerint ezek nem törnek el semmit, csak hibákat javítanak és apróbb újításokat hoznak.

  • @vapi-ai/web 2.7.1 → 3.0.0 (a Daily miatt, kódja azonos)
  • next 16.2.6 → 16.4.2, eslint-config-next 16.0.1 → 16.4.2 (a „stale” jelzés miatt)
  • react / react-dom 19.2.6 → 19.3.1
  • @clerk/nextjs 6.39.3 → 6.39.7, @clerk/localizations 3.37.9
  • @supabase/supabase-js 2.79 → 2.118, zod 4.6.7, react-hook-form 7.90
  • @sentry/nextjs 10.27 → 10.76, tailwindcss 4.3.3, Radix UI, tailwind-merge, @hookform/resolvers 5.9.2
2. lépés · külön ágon

Nagy verzióváltások átállással

Ezek törő változásokat hoznak, egyenként és teszteléssel kell őket átvinni.

  • @clerk/nextjs 7 (Clerk Core 3) + @clerk/localizations 4. A SignedIn/SignedOut helyére <Show> kerül. Van automatikus eszköz: npx @clerk/upgrade. Bónusz: ebben javították a SignInButton hibáját, amit Marci a NavAuth komponenssel került meg.
  • @sentry/nextjs 11, lucide-react 1, lottie-react 3, @hookform/resolvers 6: a kiadási jegyzetek alapján, egyenként.
Egyelőre ne

Eszközváltások

  • TypeScript 7: teljesen új, Go nyelven írt fordító. Várjuk meg, amíg a Next.js hivatalosan támogatja.
  • ESLint 10: az eslint-config-next-nek kell előbb hivatalosan támogatnia.
  • @types/node 26: a futtatott Node-verzióhoz igazodjon (22), ne a legújabbhoz.
